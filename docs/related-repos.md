# Related repositories & tools

The broader Epstein-files ecosystem on GitHub (found via search, most-starred first).
Not all are aggregated as sources — this is a map for researchers.

## Archives & mirrors (source material)
- **yung-megafone/Epstein-Files** — DataSets 1–12 + combined torrents, magnets, mirrors, integrity checks. *(primary source)*
- **beak2825/epstein-files-archive** — server responses, checksums, DOJ change/delete tracking.
- **HackTuah/doj-epstein-files** — collected release files.
- **niemasd/Epstein-Files** — EFTA (H.R.4405) scripts + files.
- **rhowardstone/Epstein-research-data** — structured exports from the 218 GB release (knowledge graph, entity extraction, image catalog).

## Search / browse / explore
- **RhysSullivan/epstein-files-browser** — web browser for the files.
- **Donnadieu/Epstein-File-Explorer** — epstein-file-explorer.com.
- **ErikVeland/epstein-archive** — processing + advanced search.
- **LMSBAND/epstein-files-db** — searchable DB, relationship graph, full-text search.
- **SvetimFM/epstein-files-visualizations** — interactive viz from the Nov 2025 House Oversight release.

## OCR / text extraction
- **LovenSar/Epstein_case_leaked_OCR_results** — OCR outputs.
- **promexdotme/epstein-justice-files-text** — 5 GB PDF set converted to clean text.
- **stonesalltheway1/Epstein-Pipeline** — download, OCR, entity extraction, dedup, export.
- **dBrogle/EpsteinProcessor** — unzip + PDF text extraction pipeline.

## RAG / LLM tooling
- **AnkitNayak-dev/EpsteinFiles-RAG** — RAG on the 'Epstein Files 20K' HF dataset.
- **AbhisumatK/Epstein_Files_RAG** — RAG over unsealed court documents.
- **CHUNKYBOI666/RAGforEpsteinFiles**
- **justinlime/epstein_rag_mcp** — load dataset into an LLM via MCP.
- **nozomio-labs/nia-epstein-ai** — 100M-word index via Nia API.
